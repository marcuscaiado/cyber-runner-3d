## ✨ Features & Highlights

- 🏃 **3-Lane High-Velocity Running**: Seamless lane-switching physics across left, center, and right tracks.
- 🚧 **Dynamic Obstacles**: Neon barriers to jump over, laser hurdles to duck under, and high-tech monoliths to avoid.
- ⚡ **Power-Up Items**:
  - 🧲 **Coin Magnet**: Automatically vacuums nearby energy tokens.
  - 🛡️ **Shield Bubble**: Protects from a fatal collision.
  - ⚡ **Hyper Boost**: Invisibility and automatic obstacle destruction at lightspeed!
- 🔊 **Procedural Web Audio**: Synthwave basslines, jump swooshes, and token collection chimes.
- 📱 **Swipe & Key Controls**: Intuitive swipe controls for mobile devices and arrow keys for desktop.

---

## 🕹️ Controls

| Action | Desktop / Keyboard | Mobile / Touch |
| :--- | :--- | :--- |
| **Change Lane** | `A / D` or `Left / Right Arrow` | Swipe Left / Right |
| **Jump** | `W` or `Up Arrow` / `[SPACE]` | Swipe Up |
| **Slide / Duck** | `S` or `Down Arrow` | Swipe Down |
